# VerdictAI frontend

Next.js 16 interface for VerdictAI. Setup, environment variables, and the API are documented in the [root README](../README.md).

```bash
npm install
npm run dev
```

The site runs at http://localhost:3000. Point `NEXT_PUBLIC_API_URL` and `NEXT_PUBLIC_VOICE_API_URL` at the API, usually `http://127.0.0.1:8000`.
